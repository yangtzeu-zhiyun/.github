## 我们做什么

**长大智耘**将农业知识、田间数据与专业工具接入大模型智能体——农业智能问答、联网检索核实、昆虫图像识别、知识库检索、智能体应用与开发者扩展，把实验室研究成果转化为农田一线可用的智能助手。

| 入口 | 说明 |
| --- | --- |
| [业务前台](https://zhiyun.lansuan.cc) | 农业智能对话、应用中心、插件市场、工作空间与定时任务 |
| [开发者中心](https://dev.zhiyun.lansuan.cc) | 技能、插件、应用与知识库四类扩展的在线开发与审核上架 |
| [管理后台](https://admin.zhiyun.lansuan.cc) | 用户、模型 Provider、审核流程与平台审计 |

## 研究背景

平台依托长江大学「虫姿百态」研究团队建设：实蝇科昆虫行为智能识别方法研究获国家自然科学基金支持，成果发表于农林与计算机交叉领域中科院一区 Top 期刊《Computers and Electronics in Agriculture》。
